# How to Compare Cold Email Tools Without Trusting Marketing Claims

To compare cold email tools objectively, define the workflow first, weight the criteria before seeing scores, and test each candidate under the same conditions. Mark every claim as observed, documented, or unverified. Do not turn a polished dashboard or an unmeasured reply-rate claim into evidence.

## A practical way to evaluate evaluation method

1. **Write must-have jobs and failure conditions before opening vendor pages.**
2. **Choose weighted criteria such as data control, sending architecture, suppression, integrations, support, and total cost.**
3. **Use the same test records, roles, provider mix, time window, and scenarios for each candidate.**
4. **Date-stamp results and publish unknowns beside scores; repeat tests when plans or workflows change.**

## Decision table

| Evidence class | Example | How to use it |
| --- | --- | --- |
| Observed | Replayed workflow or event | Highest confidence for that case |
| Documented | Current vendor terms | Verify scope and date |
| Claimed | Marketing statement | Treat as a question |
| Unknown | Not tested or disclosed | Do not score as pass |

## Edge cases and limits

A pilot does not predict long-term inbox placement because provider conditions and sending history change. Use [vendor due diligence](/repmail/learn/outreach/email-outreach-vendor-due-diligence) for procurement evidence and keep outcome claims bounded.

## A simple scoring discipline
Give each criterion a definition before assigning points. “Good integration” is too vague; “updates a test contact within the agreed window and preserves the source identifier” is testable. Use a separate column for evidence URL, test date, configuration, and reviewer. Keep a confidence label beside every score. If a vendor cannot answer a question, mark it unknown rather than awarding a neutral score that looks like partial compliance. Review the weights after testing, not during a sales call. If the choice changes when a low-confidence criterion is removed, report that sensitivity. An honest comparison can end with two finalists and an unresolved question; it does not need a forced ranking.
A short evidence register can include the test case, expected result, observed result, source, date, reviewer, confidence, and follow-up owner. Keep commercial promises in a separate section from measured behavior. That separation prevents an unverified claim from silently becoming a weighted score.
