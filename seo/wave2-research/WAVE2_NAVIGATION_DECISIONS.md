# Wave 2 Navigation Decisions

Wave 2 adds 161 articles without creating a second navigation system. All retained articles receive membership in an existing collection. Seven existing collections were extended; no collection schema changed.

The existing learning paths were extended only where an article fits an established learning sequence: provider diagnostics, cold-email message quality, email infrastructure, and list quality/suppression. The remaining **64 retained articles intentionally have no learning-path membership** because the current six-path system has no coherent sequence for agency operations, compliance governance, and glossary/reference topics. They remain discoverable through their academy, collection membership, search, related-content links, and contextual links. This is an intentional non-orphan decision, not a missing route.

No new collection or learning-path record was created. No hand-maintained route list was introduced. Article, collection, path, sitemap, RSS, canonical, structured data, and prerender behavior continue to derive from the existing loader and build pipeline.
